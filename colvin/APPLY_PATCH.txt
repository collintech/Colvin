Colvin v0.16 -> v0.16.1 Gate 7 runtime startup fix

Changes:
- Require INTERNAL_API_KEY instead of silently passing an empty value to Go services.
- Use Docker service hostnames for DATABASE_URL, VIN_DECODER_URL, HISTORY_SERVICE_URL and REDIS_URL in the local full-stack Compose runtime.
- Remove unnecessary external Dockerfile frontend pin (# syntax=docker/dockerfile:1.7) from application Dockerfiles to avoid an extra Docker Hub auth/token fetch during builds.

Before running Compose, ensure your root .env contains an INTERNAL_API_KEY of at least 24 characters.
Do not commit .env.
